# PhD Outreach Log

Master tracker for all professor outreach, organized by the date each email was sent. This file is the single source of truth for outreach status and is updated as professors respond.

**Update rule:** When a professor responds, update their `Status` and add a one-line note in `Response Notes` describing what they actually said (e.g., "lab fully funded for Fall 2027", "not accepting students this cycle", "happy to hop on a call — sent Calendly link"). Do not overwrite prior notes — append with a new dated line if there's back-and-forth.

## Status Key

| Status | Meaning |
| --- | --- |
| `Pending` | Email sent, no response yet |
| `Yes` | Positive response (interested, open to call, accepting students, etc.) |
| `No` | Declined / not accepting students / not a fit |
| `Ghosted` | No response after a reasonable follow-up window (~3-4 weeks, no reply to a follow-up) |

**Note (2026-09-16):** This session has no email-sending connector (Gmail/Outlook/SMTP) connected, so approved emails cannot be dispatched automatically yet. Approved-but-unsent drafts are tracked in `candidates/` with an "APPROVED, NOT YET SENT" marker rather than added here — a row is only added once an email has actually gone out.
